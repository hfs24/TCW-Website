STA Wireless configuration


Please turn the checkbox on to activate and configure Station mode in the module. This mode is requiered to access cloud and activate collboration and control session features.

configure WiFi Connetion


Please Fill the name or ID of your Wireless network to be accessed

Please Flll the password of Your Wirless Network
Please Fill the IP adress of your device in the standard format (X.X.X.X). If DHCP is activated , Please ignore this field
Please Fill the Network Subnet of your device in the standard format (X.X.X.X). If DHCP is activated , Please ignore this field.
Please Fill the Gateway of your device in the standard format (X.X.X.X). If DHCP is activated , Please ignore this field.




New WiFi Connetion (Scan to choose a Network)


Please Turn This checkbox on to scan and search for availables Newtworks, You can San and connect to a new available WiFi Network. This requiere to have a valid password for this Network and reboot the module in order to apply changes. Also this mode work only in DHCP mode. if you want to specify your own IP Adress, Please use the configuration mode below.
This functionnality is also available in Home menu.
